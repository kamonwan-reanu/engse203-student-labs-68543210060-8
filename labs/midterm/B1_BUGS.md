# B1 · บันทึกการแก้บั๊ก (กรอกให้ครบทั้ง 6 จุด)

> แต่ละบั๊กให้เขียน 4 อย่าง: ไฟล์ · บรรทัด · สาเหตุ (ทำไมทำงานผิด) · แก้อย่างไร
> เขียนด้วยคำของตัวเอง — จุดนี้จะถูกถามใน oral

## บั๊กที่ 1 — อาการ: Console เตือนสีเหลืองเรื่องรายการ
- ไฟล์/บรรทัด:`src/components/RequestList.jsx`
- สาเหตุ:ตอนใช้ `.map()` วนลูปสร้าง `<RequestCard />` ไม่ได้ใส่ attribute `key` ทำให้ React เตือนเรื่อง unique key prop
- แก้อย่างไร:ใส่ `key={request.id}` เพิ่มเข้าไปใน tag `<RequestCard>`

## บั๊กที่ 2 — อาการ: ตัวเลข "รอดำเนินการ" ในแผงสรุปไม่ตรงกับที่เห็น
- ไฟล์/บรรทัด:`src/pages/DashboardPage.jsx`
- สาเหตุ:เงื่อนไขนับจำนวน `pending` เขียนผิดเป็นเช็ก `request.status === 'completed'` และไม่ได้แปลงเป็นตัวพิมพ์เล็ก ทำให้ดึงค่ามานับผิดกลุ่ม
- แก้อย่างไร:เปลี่ยนเงื่อนไขเป็น `request.status?.toLowerCase() === 'pending'`

## บั๊กที่ 3 — อาการ: กดตัวกรอง "รอดำเนินการ" แล้วได้รายการที่ไม่ใช่
- ไฟล์/บรรทัด:`src/pages/DashboardPage.jsx`
- สาเหตุ:ในฟังก์ชันกรองใช้เครื่องหมายไม่เท่ากับ (`!==`) ทำให้พอกดเลือกสถานะไหน ระบบกลับไปดึงสถานะอื่นที่ไม่ใช่อันนั้นมาแสดงแทน
- แก้อย่างไร:เปลี่ยนเครื่องหมายจาก `!==` เป็น `===` เพื่อให้ดึงเฉพาะรายการที่ตรงกับตัวกรอง

## บั๊กที่ 4 — อาการ: เปลี่ยน URL จาก REQ-001 เป็น REQ-002 แล้วข้อมูลไม่เปลี่ยน
- ไฟล์/บรรทัด:`src/pages/RequestDetailPage.jsx`
- สาเหตุ:ใน `useEffect` ลืมใส่ `id` (หรือ `requestId`) ลงใน Dependency Array `[]` ทำให้ตอนเปลี่ยน URL หน้าจอไม่ยอมรันดึงข้อมูลใหม่
- แก้อย่างไร:เติม `id` เข้าไปใน Dependency Array ของ `useEffect` เป็น `[id]`

## บั๊กที่ 5 — อาการ: กด "ลบ" แล้วรายการยังอยู่ ต้องรีเฟรชถึงหาย
- ไฟล์/บรรทัด:`src/pages/DashboardPage.jsx`
- สาเหตุ:ในฟังก์ชัน `handleDelete` พอเรียก service ลบเสร็จ ดันเอาข้อมูลเก่า (`requests`) ไป `setRequests(requests)` หน้าจอเลยไม่ยอมอัปเดตตาม
- แก้อย่างไร:เปลี่ยนไปใช้ข้อมูลชุดใหม่ที่ได้จาก service มาอัปเดตแทน คือ `setRequests(nextRequests)`

## บั๊กที่ 6 — อาการ: กด "Reset Demo Data" แล้วหน้าพัง/ว่างเปล่า
- ไฟล์/บรรทัด:`src/pages/DashboardPage.jsx`
- สาเหตุ:ฟังก์ชัน `resetRequests()` เป็นแบบ asynchronous (คืนค่าเป็น Promise) แต่ตอนเรียกใช้ไม่ได้ใส่ `await` ด้านหน้า ทำให้ state ได้ค่า Promise ไปแทนที่จะเป็น array ข้อมูล
- แก้อย่างไร:เติม `await` ไว้หน้าฟังก์ชัน เป็น `const resetData = await resetRequests();`
